## 这个 App 是干什么的？

美团单车忘关锁，平台要等你停车**满 60 分钟**才自动结束订单——这期间一直在扣钱。

关锁卫士的逻辑很简单：

1. 收到美团「**开锁成功**」的通知 → 悄悄开始倒计时（50 分钟）
2. 收到「**行程结束，已为您关锁结费**」的通知 → 倒计时取消，一切安静
3. 50 分钟到了还没关锁 → **全屏通知 + 语音播报 + 震动**，提醒你去关锁

正常骑行 10~30 分钟的人，全程不会有任何打扰，只有真忘了关锁才会响。

不 root、不刷机、不碰美团 App 本身，只读取自己手机的通知栏，安全干净。

## 装完必须做的 3 步（很重要，不做等于白装）

第一次打开 App，会看到权限列表，**点每一项右边的按钮**去开启：

1. **通知使用权** —— 这是它能感知开锁/关锁的唯一途径，必须开
2. **通知权限** —— 不开它没法提醒你
3. **电池优化白名单** —— 点进去选「允许」，防止系统把它杀掉

### OPPO / 一加 / 小米 / vivo / 华为 用户再多做一步 ⚠️

国产手机的「忽略电池优化」和「允许后台运行」是**两个不同的开关**！只开前一个，App 在后台还是会被冻住，收不到开锁通知。

- **OPPO / 一加**：设置 → 应用管理 → 关锁卫士 → 耗电管理 → 打开「**允许完全后台行为**」
- **小米 / 红米**：设置 → 应用管理 → 关锁卫士 → 省电策略 → 选「**无限制**」
- **vivo**：设置 → 电池 → 后台耗电管理 → 关锁卫士 → 允许高耗电
- **华为**：设置 → 应用 → 应用启动管理 → 关锁卫士 → 关闭自动管理，三个开关全打开

**怎么确认设置成功了？** 骑一次车后打开 App，「运行诊断」里应该显示：
`监听服务：已连接（最近一次 几分钟前）`。如果显示"未授权"或很久没连上，就是上面没设置对。

## 骑行时它会做什么？

- 开锁后，状态栏会出现一条「**骑行中**」的通知，上面有个走秒的计时器
- 到 50 分钟没关锁：全屏提醒 + 语音喊你 + 震动，通知上有两个按钮：
  - **「已关锁」** —— 点一下就安静
  - **「仍在骑行」** —— 长途骑行时点它，顺延 30 分钟再提醒
- 关锁后，那条「骑行中」通知自动消失，手机恢复干净

## 不想被吵？可以调

打开 App 可以改提醒时间（比如 30 分钟），也可以先设成 2 分钟做测试：
点「模拟一次开锁」，等 2 分钟看它会不会响，会响就说明一切正常。

## 常见问题

**Q：为什么开锁后 App 里没反应？**
A：99% 是通知使用权没开，或者被国产 ROM 冻住了（见上面第 3 步）。

**Q：为什么我点进 App 才开始计时？**
A：就是后台被系统杀了。按上面"国产手机再多做一步"设置后台运行权限。

**Q：骑了超过 50 分钟的长途会一直响吗？**
A：响第一次时点「仍在骑行」，就顺延 30 分钟，不会一直吵。

**Q：耗电吗？**
A：几乎不耗电。它平时完全休眠，只在收到通知和闹钟到点时才醒一下。

## 给开发者看的部分

### 工作原理

- `NotificationListenerService` 监听 `com.sankuai.*` 与支付宝系包名的通知，关键词配对「开锁成功」/「行程结束」两类信号（见 `Signal.kt`）
- 倒计时交给 `AlarmManager`（`setExactAndAllowWhileIdle` + `ELAPSED_REALTIME_WAKEUP`）
- 会话状态 `commit()` 同步落盘，闹钟 Intent 自带会话快照，进程被杀 / 手机重启都能恢复
- 三级提醒升级：第 50 / 55 / 60 分钟
- 骑行中通知用 `setChronometer` 系统渲染走秒，进程死了照走

### 构建

**Android Studio**：直接打开本目录，Build APK。

**命令行（无 Gradle）**：

```bash
bash tools/fetch-kotlinc.sh   # 一次性：下载 Kotlin 编译器
bash tools/build-apk.sh       # aapt2 → kotlinc → d8 → apksigner
```

需要 JDK 17+ 和 Android SDK（build-tools 36 / android-36）。签名证书在 `buildtools/`（已 gitignore），**删了会导致无法覆盖安装**。

```

  RideStatusNotifier.kt        骑行中状态栏计时通知
  MainActivity.kt              设置页 / 文案自测 / 日志 / 诊断
tools/                         免 Gradle 打包脚本、logcat 采样脚本
lsposed/                       LSPosed 只读探针（调研用，非必需）
docs/                          设计文档与安装说明
```
